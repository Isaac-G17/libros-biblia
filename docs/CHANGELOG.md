# Registro de cambios

Formato basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/)
y versionado según [SemVer](https://semver.org/lang/es/).

## [1.0.0] - 2026-11-13

### Agregado
- Flujo de Aprender organizado por divisiones del canon de 66 libros.
- Juego de Practicar: preguntas de opcion multiple con retroalimentacion inmediata.
- Juego de Ordenar: colocar libros en su orden canonico por toque o teclado.
- Juego de Emparejar: libro-division (ninos) o libro-tema (adultos).
- Modo ninos y modo adultos con temas visuales independientes.
- Progreso persistido en localStorage, detras de ProgresoService.
- Despliegue automatico a GitHub Pages mediante GitHub Actions.

### Pendiente para la siguiente version
- PWA: manifest, service worker y uso offline.
- Fase 2: backend Spring Boot, login de maestros, grupos y sincronizacion.
